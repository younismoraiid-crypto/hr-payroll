# نظام الموارد البشرية والرواتب — النسخة الأونلاين

هذه النسخة تحوّل النظام من `localStorage` فقط إلى نظام ويب ببيانات مركزية على الخادم.

## الدخول الأول
- اسم المستخدم: `admin`
- كلمة المرور: `Admin@2026!`

## ماذا تغير؟
- البيانات تحفظ في الخادم داخل `data/state.json`.
- جميع الأجهزة التي تدخل بنفس الرابط ترى نفس البيانات.
- كل إضافة/تعديل/حذف يتم مزامنته تلقائياً مع الخادم.
- يوجد تسجيل دخول قبل الوصول إلى البيانات.
- إذا انقطع الاتصال، تبقى نسخة محلية مؤقتة في المتصفح.
- المشروع جاهز للنشر عبر Docker/Railway.

## تشغيل محلي
```bash
php -S 127.0.0.1:8080 -t .
```
ثم افتح `http://127.0.0.1:8080`.

## نشر Railway
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد، مثلاً `hr-payroll-online`.
2. في Railway اختر New Project ثم Deploy from GitHub Repo.
3. اختر المستودع.
4. Railway سيستخدم `Dockerfile` الموجود في المشروع.
5. بعد نجاح النشر افتح Generate Domain للحصول على الرابط.
6. أضف Volume في Railway واربطه بالمسار `/app/data` حتى تبقى بيانات الرواتب والموظفين محفوظة عند إعادة النشر أو إعادة تشغيل الخدمة.

## التحديثات على نفس الرابط
بعد إنشاء الرابط لأول مرة، لا تنشئ مشروع Railway جديداً. عدّل الملفات في نفس مستودع GitHub ثم ادفع التعديل؛ Railway يعيد نشر نفس الخدمة، ويبقى الرابط نفسه.

## مهم
غيّر كلمة مرور المدير قبل الاستخدام الفعلي. النسخة الحالية تستخدم مستخدماً واحداً فقط. يمكن إضافة لاحقاً: مستخدمين وصلاحيات، نسخ احتياطي، سجل عمليات، وتغيير كلمة المرور من داخل النظام.
